# 3-minute demo script

## 0:00–0:30 — Problem

"Suppose a gig worker has ₹5,000. A banking app says ₹5,000 is available. But rent, fuel and uncertain income may make most of that balance unsafe to spend."

## 0:30–1:00 — Dashboard

Show:

- balance
- safe-to-spend
- safety floor
- resilience score
- Financial Weather

Say:

"Our system looks forward instead of only backward."

## 1:00–1:45 — Financial Digital Twin

Show income forecast.

"Prophet forecasts near-term earnings from historical gig income. We combine that with expense patterns and upcoming obligations."

## 1:45–2:30 — What-if

Set:

- income change = -30%
- unable to work = 2 days
- unexpected expense = ₹1,000

Run scenario.

"Now the user can see the consequence before taking action."

## 2:30–3:00 — Differentiation

"Existing products can provide payouts, earned-wage access, savings or credit. Our system is the decision layer that asks: what action is safest for the worker right now?"

End with:

"We are not building another lending app. We are building a financial shock absorber."
